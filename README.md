# Cybersecurity Lab Setup

## 1. Project Overview
This project involved setting up a virtual cybersecurity laboratory using Oracle VirtualBox and Kali Linux. The laboratory provides a controlled environment for learning and practising cybersecurity concepts, particularly network security and traffic analysis.

## 2. Objectives
- Install and configure Oracle VirtualBox.
- Install and configure Kali Linux.
- Configure a virtual network for communication between virtual machines.
- Establish an environment for practical cybersecurity exercises.

## 3. Lab Configuration
The laboratory consists of:
- **Host Operating System:** Windows
- **Virtualisation Platform:** Oracle VirtualBox
- **Guest Operating System:** Kali Linux
- **Network Configuration:** NAT Network
- **Network Address Range:** 10.0.0.0/24

## 4. Setup and Verification
Oracle VirtualBox was installed and configured, followed by the installation of Kali Linux as a virtual machine. A NAT Network was configured to provide network connectivity and internet access.

The setup was verified by successfully running Kali Linux and confirming network connectivity.
